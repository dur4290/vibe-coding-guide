# /save — 작업 저장 (git commit + push)

오늘 작업한 내용을 git에 저장하고 GitHub에 올립니다.

## 사용법

```
/save
/save 오늘 파일 정리 자동화 완성
```

---

## 실행 순서

### 1단계: 보안 확인 (필수)

`git diff --cached`와 스테이징된 파일 목록을 확인해:

- `.env` 파일이 포함되어 있으면 **즉시 중단**하고 나에게 알려줘
- 다음 패턴이 코드에 있으면 **즉시 중단**:
  - `sk-ant-`, `sk-proj-` (API 키)
  - `ANTHROPIC_API_KEY = "sk` (직접 입력된 API 키)
  - `password = "` (비밀번호 직접 입력)

보안 문제 발견 시: 커밋하지 말고 어떤 파일의 어느 부분인지 알려줘.

### 2단계: 변경 내용 확인

```bash
git status
git diff --stat
```

변경된 파일이 없으면 나에게 알려주고 끝내.

### 3단계: 커밋 메시지 작성

변경된 파일들을 보고 적절한 커밋 메시지를 제안해줘.

사용자가 직접 메시지를 줬으면 그걸 사용해.

형식: `작업내용 요약 (예: 파일 정리 자동화 스크립트 추가)`

### 4단계: 저장 실행

```bash
git add .
git commit -m "커밋 메시지"
git push
```

### 5단계: 결과 알려주기

- 성공: 어떤 파일이 저장됐는지 알려줘
- 실패: 오류 메시지를 분석해서 해결 방법 알려줘
  - push가 실패하면: remote 설정 확인, 브랜치 확인
  - commit이 실패하면: pre-commit 훅 오류 확인

---

## 주의사항

- 보안 확인을 절대 건너뛰지 마
- `git add .` 전에 반드시 `git status`로 뭐가 올라가는지 확인해
- 처음 push할 때 remote가 없으면 GitHub 저장소 생성 방법을 안내해줘
