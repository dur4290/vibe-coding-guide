Ch2. Claude Code 시작하기

Chapter 2 ⏱ 약 30분

이 챕터에서는 AI 코딩 도구인 Claude Code를 설치하고 첫 대화를 나눠봅니다. Claude Code가 설치되면 터미널에서 AI에게 말을 걸고, AI가 직접 코드를 만들어줍니다.

⚠️
Claude Pro 구독이 필요합니다
Claude Code를 사용하려면 claude.ai에서 Pro 구독(월 약 ₩30,000)이 되어 있어야 합니다. 아직 구독하지 않았다면 먼저 구독하고 돌아오세요.

1. Node.js 설치하기

Claude Code CLI를 설치하려면 Node.js가 필요합니다. Node.js는 JavaScript를 실행하는 환경입니다. 직접 코드를 짜진 않지만 Claude Code가 내부적으로 사용해요.

1

Node.js 다운로드

nodejs.org에 접속해서 LTS 버전을 다운로드하세요. (LTS = 안정 버전)

2

Node.js 설치 확인

VSCode 터미널을 열고 (Ctrl + `) 아래 명령어를 실행해보세요:

node --version

아래처럼 버전이 나오면 성공입니다:

v22.0.0

2. Claude Code 설치하기

1

Claude Code CLI 설치

VSCode 터미널에 아래 명령어를 입력하고 Enter를 누르세요:

npm install -g @anthropic-ai/claude-code

설치가 시작되고 잠시 기다리면 완료됩니다.

Node.js 설치 후 VSCode를 완전히 닫았다가 다시 열어보세요. 그래도 안 되면 시작 메뉴 검색창에서 PowerShell을 관리자 권한으로 실행해서 같은 명령어를 입력해보세요.
2

첫 실행 및 로그인

터미널에 아래 명령어를 입력하세요:

claude

처음 실행하면 로그인을 요청합니다. 브라우저가 자동으로 열리면서 claude.ai 로그인 화면이 나옵니다. Claude Pro 계정으로 로그인하면 됩니다.

💡
브라우저에서 로그인 완료 후 터미널로 돌아오면 Claude Code가 준비됩니다. claude.ai에 가입된 이메일로 로그인하세요.

3. 첫 대화 테스트

로그인이 완료되면 터미널에 프롬프트가 나타납니다. AI에게 인사해봅시다!

1

AI에게 인사하기

Claude Code 프롬프트에 아래처럼 입력해보세요:

안녕하세요! 저는 코딩 초보입니다. 자기소개 해주세요.

AI가 자기소개를 하면 연결 성공입니다! 🎉

2

Claude Code 종료하기

Claude Code를 종료하려면 /exit를 입력하거나 Ctrl + C를 누르세요.

/exit
💡
Claude Code 꿀팁
Claude Code는 현재 열려있는 폴더의 파일들을 볼 수 있습니다. 폴더를 VSCode로 열고 터미널에서 claude를 실행하면, AI가 그 폴더의 파일들을 이해하면서 도와줍니다.

🎉 Ch2 완료!
