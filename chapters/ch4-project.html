2. Claude Code에 스크립트 만들어달라고 요청하기

이제 AI에게 원하는 것을 말해볼 차례입니다. 코드를 알 필요 없어요 — 원하는 걸 설명하면 됩니다!

1

첫 번째 요청 보내기

Claude Code 프롬프트에 아래 내용을 입력하세요 (그대로 복사해서 사용해도 됩니다):

내 다운로드 폴더(C:\Users\사용자이름\Downloads)를 정리해주는 Python 스크립트를 만들어줘.

조건:
- PDF 파일은 '문서' 폴더로 이동
- 이미지 파일(jpg, jpeg, png, gif, webp)은 '사진' 폴더로 이동
- 음악 파일(mp3, wav, flac)은 '음악' 폴더로 이동
- 그 외 파일은 '기타' 폴더로 이동
- 폴더가 없으면 자동으로 만들어줘
- 각 줄에 주석으로 설명도 달아줘
⚠️
사용자이름 부분을 내 Windows 사용자 이름으로 바꾸세요. 잘 모르면 "내 다운로드 폴더 경로를 먼저 알려줘"라고 AI에게 물어봐도 됩니다.
2

생성된 코드 확인하기

AI가 organize.py 같은 이름으로 파일을 만들어줄 거예요. VSCode 왼쪽 파일 탐색기에서 확인해보세요.

파일을 열어보면 아래와 비슷한 코드가 있을 거예요:

import os
import shutil

# 다운로드 폴더 경로
downloads = r"C:\Users\사용자이름\Downloads"

# 확장자별 폴더 분류
categories = {
    "문서": [".pdf"],
    "사진": [".jpg", ".jpeg", ".png", ".gif", ".webp"],
    "음악": [".mp3", ".wav", ".flac"],
}

# 파일 목록을 순서대로 확인
for filename in os.listdir(downloads):
    filepath = os.path.join(downloads, filename)

    # 폴더는 건너뜀
    if os.path.isdir(filepath):
        continue

    # 확장자 추출
    _, ext = os.path.splitext(filename)
    ext = ext.lower()

    # 해당 카테고리 폴더로 이동
    moved = False
    for folder, extensions in categories.items():
        if ext in extensions:
            dest = os.path.join(downloads, folder)
            os.makedirs(dest, exist_ok=True)
            shutil.move(filepath, os.path.join(dest, filename))
            moved = True
            break

    # 분류 안 됐으면 기타로
    if not moved:
        dest = os.path.join(downloads, "기타")
        os.makedirs(dest, exist_ok=True)
        shutil.move(filepath, os.path.join(dest, filename))

이 코드를 초보자도 이해할 수 있게 한 줄씩 설명해줘

3. 실제로 실행해보기

⚠️
실행 전 확인!
스크립트가 실행되면 파일이 실제로 이동됩니다. 다운로드 폴더에 중요한 파일이 없는지 먼저 확인하거나, 연습용 빈 폴더로 테스트해보세요.
1

테스트 폴더 만들기 (권장)

실제 다운로드 폴더 대신, 테스트용 폴더를 만들어서 먼저 해봅시다. Claude Code에게 이렇게 요청하세요:

바탕화면에 'test-downloads' 폴더를 만들고,
안에 테스트용 파일들(확장자만 다른 빈 파일 5개 정도)을 만들어줘.
그리고 스크립트가 그 폴더를 대상으로 실행되도록 경로를 바꿔줘.
2

스크립트 실행하기

Claude Code를 잠깐 종료하고 (/exit), 일반 터미널에서 실행해봅시다:

python organize.py

실행 후 테스트 폴더를 열어보면 파일들이 분류되어 있을 거예요! 🎉

git push -u origin main
