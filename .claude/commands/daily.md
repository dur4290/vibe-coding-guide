# /daily — 오늘 하루 기록

오늘 한 작업, 배운 것, 막힌 것을 간단하게 기록합니다.

## 사용법

```
/daily
```

---

## 실행 순서

1. 오늘 날짜(KST 기준)를 확인해
2. `notes/daily/` 폴더가 없으면 만들어
3. 파일 이름: `YYYY-MM-DD.md`
4. 파일이 이미 있으면 열어서 추가, 없으면 템플릿으로 새로 만들어
5. 오늘 작업 내용을 간단히 정리해줘:
   - 이번 대화에서 만든 파일, 스크립트, 프로젝트 목록
   - git log로 오늘 커밋 내역 확인 (있으면)
6. 내용 채운 뒤 파일 경로 알려줘

---

## 파일 템플릿

```markdown
---
date: YYYY-MM-DD
---

# YYYY-MM-DD 기록

## 오늘 한 것
- 

## 배운 것
- 

## 막힌 것 / 내일 할 것
- 

## 메모

```

---

## 주의사항

- 길게 쓸 필요 없어. 핵심만 짧게 쓰는 게 좋아
- 막힌 것이 있으면 그냥 솔직하게 적어줘. 내일 Claude에게 보여주면 돼
- 기존 파일이 있으면 오늘 내용을 아래에 이어서 추가해줘 (덮어쓰지 마)
