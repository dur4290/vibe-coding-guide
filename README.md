# ⚡ 내 바이브코딩 워크스페이스

AI와 함께 자동화를 만들고, 코딩을 배우고, 프로젝트를 쌓아가는 공간입니다.

---

## 처음 시작하는 방법

### 1단계: 초기 설정 (딱 한 번만)

PowerShell 터미널에서:

```powershell
.\setup.ps1
```

이 스크립트가 자동으로:
- 🔐 API 키 보안 훅을 설정해줍니다
- 👤 Git 사용자 정보를 등록합니다
- 📄 `.env.example` 파일을 생성합니다

### 2단계: VSCode에서 이 폴더 열기

**파일 → 폴더 열기** → 이 폴더(`vibe-workspace`) 선택

### 3단계: Claude Code 시작

VSCode 터미널(`Ctrl + 백틱`)에서:

```bash
claude
```

---

## 폴더 구조

```
vibe-workspace/
├── projects/          ← 내 프로젝트들
├── scripts/           ← 완성된 자동화 스크립트
├── notes/             ← 메모, 아이디어
└── .claude/
    └── skills/        ← 내가 만든 재사용 스킬들
```

---

## Claude Code와 함께 작업하는 법

### 새 프로젝트 시작
```
새 프로젝트 시작할게. [프로젝트 설명]
```

### 자동화 스크립트 만들기
```
[원하는 자동화 설명]하는 Python 스크립트 만들어줘
```

### 새 스킬 만들기
```
[기능 설명] 스킬 만들어줘
```

### 오류 해결
```
이 오류 났어: [오류 메시지 붙여넣기]
```

---

## 🔐 보안 규칙

- **API 키는 `.env` 파일에만** 저장하세요
- **`.env`는 절대 GitHub에 올리지 마세요** (`.gitignore`가 막아주지만, 직접 확인도 하세요)
- 커밋할 때마다 보안 훅이 자동으로 검사합니다

---

## 스킬 만들기

`.claude/skills/` 폴더에 자주 쓰는 기능을 스킬로 만들어두면 재사용이 편해요.

Claude Code에게:
```
파일 정리 스킬 만들어줘
```

라고 하면 `.claude/skills/_template/SKILL.md`를 참고해서 새 스킬을 만들어줍니다.
