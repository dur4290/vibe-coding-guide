# 내 바이브코딩 워크스페이스

이 폴더는 바이브코딩 실습용 폴더입니다.
코딩을 배우면서 Claude Code와 함께 작업하는 공간이에요.

## 나에 대해
- 나는 코딩을 처음 배우는 중이야
- 어려운 개념은 쉽게 설명해줘
- 모르는 용어가 나오면 바로 알려줘

## 대화 규칙
- 항상 한국어로 답변해줘
- 코드를 만들면 각 줄이 무슨 역할인지 주석으로 설명해줘
- 뭔가 잘못됐을 때 원인을 쉽게 설명해줘
- 다음 단계가 뭔지 항상 알려줘

## 현재 실습 프로젝트
파일/폴더 정리 자동화 스크립트 만들기

**목표**: 다운로드 폴더 안의 파일들을 확장자별로 자동으로 분류하는 Python 스크립트

## 환경 정보
- OS: Windows
- Python: Anaconda
- 에디터: VSCode
